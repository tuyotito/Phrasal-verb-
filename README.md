# Phrasal verbs

Application pour apprendre 1000 phrasal verbs anglais (traduction française + phrase d’exemple).
Cartes, quiz, liste, deux sens (EN → FR et FR → EN), progression enregistrée, mode sombre.
Fonctionne sans internet : les polices sont intégrées dans `www/index.html`.

## Obtenir l’APK

1. Dépose tous les fichiers de ce dépôt sur GitHub (branche `main`).
2. Onglet **Actions** → **Build APK** → **Run workflow** (ou attends la fin du lancement automatique).
3. Ouvre l’exécution terminée, section **Artifacts**, télécharge `phrasal-verbs-apk`.
4. Décompresse, envoie `app-debug.apk` sur le téléphone et installe-le.

## Contenu à relire

Les traductions et les exemples n’ont pas été relus par une source externe.
Les verbes sont dans le tableau `D` de `www/index.html`.
